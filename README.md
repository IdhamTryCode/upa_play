# 🧩 Upa's Playground

Game puzzle jigsaw sederhana untuk anak-anak berbasis web.

## Fitur

- 9 gambar puzzle berbeda
- 2 tingkat kesulitan (2x2 dan 3x3)
- Efek suara saat potongan puzzle diletakkan dengan benar
- Musik latar yang dapat dimatikan/dinyalakan
- Desain responsif yang berfungsi di desktop dan mobile

## Cara Bermain

1. Pilih gambar puzzle yang ingin dimainkan
2. Tarik kepingan puzzle dari kotak kiri
3. Letakkan pada posisi yang tepat di kotak kanan
4. Selesaikan puzzle untuk melihat pesan sukses

## Teknologi

- HTML5
- CSS3
- JavaScript (vanilla)

## Deployment

Proyek ini di-deploy menggunakan Vercel.
